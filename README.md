# Campus Lost & Found

A web-based platform that helps students report, browse, and manage lost and found items on campus.

## Features

- **User Authentication:** Secure registration and login.
- **Report Items:** Submit lost or found reports with descriptions, locations, dates, and photos.
- **Browse Reports:** Explore lost and found items.
- **Manage Reports:** Edit your reports and update their status.
- **Secure Image Uploads:** Upload item photographs with file validation.
- **Access Control:** Prevents unauthorized modifications to reports.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Database:** SQLite, Flask-SQLAlchemy
- **Authentication:** Flask-Login
- **Deployment:** Render, Gunicorn
